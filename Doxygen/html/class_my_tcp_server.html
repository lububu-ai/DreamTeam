Подробное описание

Класс асинхронного TCP-сервера, управляющий подключениями клиентов.

  • Данный класс инициализирует прослушивание входящего порта, отслеживает жизненный цикл сетевых сокетов, принимает сырые байты от клиентов, перенаправляет их парсеру команд и отправляет сформированные ответы обратно.

Конструктор класса.

  • Инициализирует объект QTcpServer, связывает сигнал нового подключения со слотом slotNewConnection(), начинает прослушивание всех сетевых интерфейсов на порту 33333, а также сбрасывает все активные соединения в базе данных.
  • Аргументы
    parentУказатель на родительский объект QObject (по умолчанию nullptr). Указатель на объект QTcpServer.
    Конструктор связывает сигнал нового подключения с обработчиком slotNewConnection(). Запускает прослушивание порта 33333 на всех доступных сетевых интерфейсах. При успешном старте или ошибке выводится сообщение в отладочный лог. Также принудительно сбрасывает старые активные соединения в базе данных, оставшиеся от предыдущего сеанса.

Деструктор класса.

  • Выполняет корректное закрытие сервера: принудительно разрывает соединения со всеми активными клиентами, вызывает для каждого из них процедуру выхода (log_out) в базе данных, очищает карту сокетов и останавливает прослушивание порта.

    Деструктор проходит по всем сокетам в карте подключений, принудительно разрывает сессию пользователя в базе данных (вызывает log_out) и безопасно удаляет объекты сокетов. После этого закрывает сам сервер.

void MyTcpServer::slotNewConnection ( )
slot

Слот для обработки нового входящего подключения.

  • Извлекает сокет из очереди ожидающих подключений, отправляет клиенту приветственное сообщение "connected\\r\\n", связывает сигналы чтения данных (readyRead) и отключения (disconnected) с соответствующими слотами и регистрирует сокет во внутренней карте mSockets.

    Циклически забирает все ожидающие подключения из очереди QTcpServer. Каждому новому клиенту отправляет текстовый маркер подключения "connected\r\n". Подключает сигналы readyRead и disconnected к соответствующим внутренним слотам сервера. Добавляет сокет во внутренний контейнер mSockets по его дескриптору.

◆ slotServerRead

void MyTcpServer::slotServerRead ( )
slot

Слот для чтения входящих данных от клиента.

  • Вызывается, когда в сокет поступают байты. Накапливает полученные данные, логирует их, передает на обработку в CommandParser и отправляет полученную текстовую строку ответа обратно клиенту.

    Определяет, от какого именно сокета пришли данные (с помощью qobject_cast). Считывает все доступные байты из потока сокета. Если встречает символ \x01, отправляет накопленный буфер ответа обратно, иначе накапливает строку команды. Полученная полная строка отправляется на обработку в CommandParser, результат которой записывается в сокет клиента.
