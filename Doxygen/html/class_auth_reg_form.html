Подробное описание

Класс формы интерфейса, отвечающий за ввод учетных данных пользователя.

  • Позволяет переключаться между экранами входа и создания новой учетной записи, валидирует поля ввода и передает их сетевым функциям.

Слот нажатия кнопки «Войти». Вызывает логику проверки логина и пароля.

Слот обработки нажатия кнопки «Войти».

  • Извлекает данные из полей ввода, вызывает функцию auth() и, в случае успеха, генерирует сигнал auth_ok(role), скрывая текущее окно. При ошибке выводит QMessageBox.

privateslot

Слот нажатия кнопки «Зарегистрироваться». Отправляет данные на сервер для добавления в БД.

Слот обработки нажатия кнопки «Зарегистрироваться».

  • Проверяет совпадение паролей. Если проверка пройдена, отправляет регистрационные данные на сервер. При успешном ответе авторизует пользователя и отправляет сигнал auth_ok(role).
