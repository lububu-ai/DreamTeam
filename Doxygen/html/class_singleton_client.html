Класс синглтона для отправки запросов на сервер через QTcpSocket.

  • Гарантирует наличие единой точки отправки сообщений и постоянного сетевого соединения на протяжении всей работы клиентской сессии.

Синхронная/блокирующая отправка текстового запроса на сервер и ожидание ответа.

Синхронный метод отправки сообщения на сервер с ожиданием ответа.

queryТекстовая команда протокола.
Возвращает
