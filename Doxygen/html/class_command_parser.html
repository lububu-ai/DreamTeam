Конструктор по умолчанию. Инициализирует карту доступных команд и привязывает их к функциям из commands.h.

Методы

◆ parse()

QString CommandParser::parse ( QString input_command,
int socket_descriptor )

Разбирает входящую строку команды и вызывает нужный обработчик.

Аргументы
input_commandПолная строка команды, полученная от клиента.
socket_descriptorДескриптор сокета клиента, отправившего команду.
Возвращает
QString Ответ сервера, готовый к отправке обратно клиенту.

Выполняет очистку строки от пробельных символов, разбивает её по пробелам на имя команды и аргументы. Если команда найдена в списке зарегистрированных, вызывает привязанный обработчик. В противном случае возвращает статус ошибки.
