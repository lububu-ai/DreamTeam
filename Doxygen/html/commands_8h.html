◆ generate_task()

CurrentTask generate_task ( int task_type)

Генератор случайных задач по типам.

  • Поддерживает 5 различных математических/алгоритмических задач:
  • 1: Формула Симпсона (Мусихин)
  • 2: Метод хорд / Линейные функции (Филатов)
  • 3: Дихотомия / деление отрезка (Шилова)
  • 4: Поиск листьев в дереве обходом в глубину (Семенец)
  • 5: Вычисление аналитической функции с логарифмом и корнем (Рыбакин)
    Аргументы
    task_typeИдентификатор типа задачи (от 1 до 5).
    Возвращает
    CurrentTask Структура с типом, payload-строкой параметров и строкой правильного ответа.
    Генерирует уникальный вариант задачи в зависимости от переданного числового типа (1..5). Наполняет payload параметрами, преобразует правильный математический ответ в строку с нужной точностью.
  • Задача 1: Формула численного интегрирования Симпсона.
  • Задача 2: Метод хорд для нелинейных уравнений.
  • Задача 3: Метод дихотомии (деления отрезка пополам).
  • Задача 4: Поиск листьев графа (дерева) с помощью алгоритма обхода в глубину (DFS).
  • Задача 5: Вычисление выражения с аналитической функцией (логарифмы/корни).
